# Аптечна Система за Управление на Лекарства

Уеб приложение за управление на инвентара в аптека, разработено с Next.js и React.

## Функционалности

### Основни операции
- **Добавяне на лекарства** - Въвеждане на ново лекарство с име, цена, количество, срок на годност и минимално ниво на запас
- **Редактиране** - Промяна на данните на съществуващо лекарство
- **Изтриване** - Премахване на лекарство от системата с плавна анимация

### Търсене и филтриране
- **Търсене по име** - Реално време филтриране докато пишете
- **Филтър "Над 5 лв"** - Показване само на лекарства с цена над 5 лева
- **Филтър "Изтичащ срок"** - Намиране на лекарства с конкретна дата на изтичане
- **Филтър "Нисък запас"** - Показване на лекарства под минималното ниво

### Сортиране
- По име (А-Я / Я-А)
- По цена (ниска към висока / висока към ниска)
- По срок на годност (скоро изтичащи първо / последни)
- По количество (малко към много / много към малко)

### Предупреждения
- **Нисък запас** - Жълто маркиране на лекарства под минималния праг
- **Скоро изтичащ срок** - Оранжев индикатор за лекарства с валидност под 30 дни

### Импорт/Експорт
- **CSV Експорт** - Изтегляне на целия инвентар като CSV файл
- **CSV Импорт** - Зареждане на лекарства от CSV файл с валидация

## Технологии

- **Framework**: Next.js 15 (App Router)
- **UI библиотека**: React 19
- **Стилизиране**: Tailwind CSS v4
- **Компоненти**: shadcn/ui
- **Икони**: Lucide React
- **Език**: TypeScript
- **Backend (Mock API)**: json-server

## Инсталация

```bash
# Клониране на репозиторито
git clone https://github.com/martinski74/pharmacy.git
cd pharmacy

# Инсталиране на зависимости
npm install

# Стартиране на json-server + приложението
npm run dev
```

По подразбиране:
- Приложението е достъпно на `http://localhost:3000`
- JSON API е достъпен на `http://localhost:3001/medicines`

## Development скриптове

- `npm run dev` - стартира `json-server` и Next.js заедно
- `npm run dev:db` - стартира само `json-server` на порт `3001`
- `npm run dev:app` - стартира само Next.js приложението

## CSV Формат

При импорт на CSV файл, структурата трябва да бъде:

```csv
name,price,quantity,expiryDate,minStockLevel
Аспирин,3.50,50,2027-06-30,10
Парацетамол,4.00,25,2026-04-15,15
```

**Полета:**
- `name` - Име на лекарството (задължително)
- `price` - Цена в лева (число)
- `quantity` - Налично количество (цяло число)
- `expiryDate` - Срок на годност (YYYY-MM-DD формат)
- `minStockLevel` - Минимален праг за предупреждение (по подразбиране: 10)
